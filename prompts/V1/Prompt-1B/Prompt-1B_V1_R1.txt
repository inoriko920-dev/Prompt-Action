Prompt 1B membuat tepat SATU DOCX untuk setiap part. Di dalam file yang sama terdapat dua lapisan: (1) Bagian A teknis lengkap sebagai sumber pembanding dan (2) NASKAH BERSIH di bagian paling bawah untuk diedit pengguna. File ini belum menjadi sumber final Prompt 1B2 sebelum diselaraskan dan dikunci oleh Prompt 1B1.

# TUGAS PROMPT 1B

1. Menentukan titik awal dan akhir part.
2. Menulis narasi lengkap dalam bahasa Indonesia yang natural dan nyaman dibacakan.
3. Menjadikan narasi sebagai pembawa utama alur, bukan sekadar pengantar menuju dialog.
4. Menyelesaikan narasi scene lebih dahulu sampai situasi, tindakan, alasan, akibat, dan perkembangan berikutnya terbaca.
5. Setelah narasi lengkap, memilih hanya dialog atau aksi asli yang benar-benar menambah kekuatan emosi, karakter, pengungkapan, keputusan, ancaman, atau klimaks.
6. Menjaga sasaran normal sekitar 70–80% informasi alur dibawa narasi dan sekitar 20–30% diperkuat dialog atau aksi asli. Angka ini adalah audit keseimbangan informasi, bukan kuota kata atau durasi matematis.
7. Memindahkan seluruh informasi penting dari dialog yang tidak dipilih ke narasi secara kronologis dan natural tanpa mengarang fakta.
8. Untuk Jangkar DIALOG, gunakan default 1 unit D untuk satu beat. D kedua hanya dipakai bila dua ucapan benar-benar saling membutuhkan; jangan menyimpan percakapan hanya karena masih berlangsung.

10. Untuk Jangkar CAMPURAN, aksi tetap menjadi fokus utama dan dialog hanya penguat singkat; setiap D di dalam CAMPURAN tetap maksimal 3,00 detik.
11. Menjadikan satu jangkar sebagai satu beat utama, bukan satu jangkar untuk setiap kalimat penting.
12. Memastikan jumlah jangkar mengikuti perubahan cerita yang nyata, bukan target angka dan bukan jumlah baris dialog.
13. Menentukan beat aksi penting dan setelah seleksi normal melakukan Audit Jangkar Aksi Terlewat.
14. Mengelompokkan perpindahan scene besar dan beat penting dalam scene panjang.
15. Membagi pertarungan panjang menjadi beberapa fase yang wajar.
16. Menempatkan narasi di antara fase pertarungan apabila diperlukan agar blok aksi tidak terlalu panjang.
17. Memberikan rentang sumber atau timestamp kandidat.
18. Menjaga kontinuitas dengan part sebelumnya dan berikutnya.
19. Khusus Part 1, membuat tiga alternatif pembukaan, memilih satu yang paling natural sebagai pembukaan final, dan menyimpan dua alternatif lain di bagian terpisah.
20. Memastikan Part 2 dan seterusnya langsung melanjutkan cerita tanpa pembukaan ulang atau penyebutan nomor part.
21. Memastikan part berakhir pada adegan atau Jangkar terakhir tanpa narasi penutup apabila adegan tersebut sudah jelas.
22. Membuat Bagian A teknis lengkap dan Bagian B Naskah Bersih Edit Manual dalam satu DOCX, lalu memakai file yang sama sebagai input Prompt 1B1 untuk menyelaraskan perubahan narasi, dialog, timestamp, durasi, nomor, jenis jangkar, dan audit keseimbangan sebelum masuk Prompt 1B2.

# NARASI

Narasi adalah tulang punggung cerita. Penonton harus tetap dapat memahami alur utama hanya dengan membaca seluruh blok narasi, meskipun dialog asli belum diputar.

Narasi harus:

* Natural, mengalir, santai, jelas, dan nyaman untuk voice-over.
* Kronologis dan bergerak maju.
* Menjelaskan situasi, tindakan, alasan, akibat, serta perkembangan berikutnya sesuai kebutuhan scene.
* Membawa sebagian besar informasi penting tentang keputusan, perubahan hubungan, ancaman, rencana, petunjuk, dan akibat.
* Tidak kehilangan informasi penting hanya karena dialog tertentu tidak dipilih.
* Tidak berhenti terlalu cepat hanya karena setelahnya akan ada dialog.
* Tidak mengulang utuh isi dialog terpilih tepat sebelum dialog diputar.
* Tidak terlalu singkat.
* Tidak bertele-tele.
* Tidak mengarang kejadian.
* Tidak menjelaskan detail visual yang tidak perlu apabila sudah jelas dari gambar.
* Tidak wajib menceritakan setiap gerakan kecil.
* Dilarang berdiri sendiri di antara dua jangkar tanpa visual.
* Untuk Part 2 dan seterusnya, wajib langsung meneruskan cerita tanpa rangkuman pembuka.
* Pada akhir part, dilarang memberi rangkuman penutup, teaser, prediksi, atau kalimat seperti “cerita berlanjut”.

Aturan praktis:

1. Tulis narasi scene sampai hubungan sebab-akibat terbaca.
2. Lihat apakah informasi penting tetap dapat dipahami jika seluruh dialog asli dihapus.
3. Jika tidak, pindahkan informasi dari dialog yang tidak dipilih ke narasi.
4. Setelah itu baru sisipkan dialog atau aksi asli sebagai penguat.

Contoh prinsip:

Kurang tepat:

`Raka mendatangi gudang. "Aku tahu kau berbohong." Ia lalu pergi.`

Lebih baik:

`Raka mendatangi gudang setelah menemukan bukti bahwa laporan Dimas tidak sesuai dengan kenyataan. Ia menahan kecurigaannya sampai mereka berhadapan langsung.`

Dialog jangkar:

`“Aku tahu kau berbohong.”`

Kemudian narasi melanjutkan akibat dialog tersebut.

Target umum 70–80% narasi dan 20–30% dialog/aksi dipakai sebagai audit keseimbangan informasi, bukan hitungan kata yang kaku.

Apabila keseimbangan menyimpang jauh karena alasan artistik yang valid, jelaskan alasannya pada catatan teknis.

# ATURAN DIALOG TERPILIH

Dialog dipakai secara selektif sebagai penguat, bukan sebagai pembawa sebagian besar informasi alur.

Pertahankan dialog apabila:

* Menjadi klimaks emosional.
* Mengandung pengungkapan yang jauh lebih kuat bila didengar langsung.
* Menunjukkan karakter secara khas.
* Merupakan keputusan besar.
* Menjadi ancaman, pengakuan, perintah, atau jawaban penting.
* Intonasi, jeda, atau ekspresinya memiliki nilai yang hilang bila seluruhnya diparafrasekan.

Jika dialog tidak memenuhi salah satu fungsi di atas:

* Informasinya dipindahkan ke narasi apabila penting.
* Dialog aslinya tidak wajib dijadikan jangkar.

Aturan wajib Dialog:

1. Satu beat dialog default = satu D-xxx.
2. D kedua hanya dipakai bila dua ucapan benar-benar saling membutuhkan agar maknanya utuh.
3. Jangan menyimpan dialog pertama hanya karena percakapan berlanjut ke dialog berikutnya.
4. Setiap D-xxx maksimal 3,00 detik. Gunakan bagian sesingkat mungkin; 3,00 detik bukan durasi target.
5. Jika makna penuh membutuhkan lebih dari 3,00 detik, pecah menjadi dua D hanya bila keduanya benar-benar diperlukan. Jika tidak, pindahkan sisa informasinya ke narasi.
6. Bila satu percakapan memiliki tiga ucapan penting yang dapat berdiri sendiri, pilih hanya ucapan terkuat dan pindahkan informasi lainnya ke narasi.
7. Jika dua dialog terpilih terpisah oleh perkembangan narasi yang nyata, pisahkan menjadi jangkar berbeda.
8. Jika satu Jangkar CAMPURAN mengandung dialog, setiap D di dalamnya tetap tunduk pada batas 3,00 detik.

Audit akhir Dialog:

* Hitung jumlah D terpilih.
* Tandai pasangan D berturut-turut tanpa narasi atau aksi pemisah.
* Untuk setiap pasangan, tanyakan apakah D kedua benar-benar membutuhkan D pertama.
* Jika tidak, simpan dialog terkuat saja dan pindahkan isi dialog lain ke narasi.
* Catat bila rasio dialog/aksi menjadi tinggi karena satu scene memang membutuhkan performa asli.

# JANGKAR

Jangkar adalah adegan film asli yang nanti digunakan oleh Prompt 1B2 untuk pembagian wilayah visual dan dilanjutkan ke Prompt 2.

Jenis jangkar:

* DIALOG.
* AKSI.
* CAMPURAN.
* TRANSISI.

Satu jangkar idealnya mewakili satu beat utama.

Contoh beat utama:

* Pertemuan.
* Penolakan.
* Keputusan.
* Pengungkapan.
* Ancaman.
* Serangan.
* Reaksi besar.
* Kematian.
* Perubahan lokasi.
* Akibat penting.

Jangan membuat satu jangkar untuk setiap baris dialog apabila seluruh percakapan masih merupakan satu beat.

Jangan memecah satu percakapan menjadi banyak jangkar kecil hanya karena setiap kalimat terasa penting.

# JUMLAH JANGKAR TANPA BATAS ANGKA

Tidak ada target minimum, maksimum, 8–10, atau batas lunak 12 jangkar.

Jumlah jangkar mengikuti struktur cerita aktual.

Dilarang:

* Mengurangi jangkar penting hanya karena jumlahnya banyak.
* Menambah jangkar palsu hanya agar jumlahnya terlihat banyak.
* Menggabungkan beat yang seharusnya terpisah hanya untuk mengejar angka.

Setelah Audit Dialog dan Audit Jangkar Aksi selesai, jumlah akhir jangkar adalah hasil aktual part.

# ATURAN JANGKAR DIALOG

Jika jangkar DIALOG dipilih:

1. Tentukan satu beat yang ingin dipertahankan.
2. Pilih dialog terkuat dalam beat tersebut.
3. Default hanya satu D.
4. D kedua harus memiliki alasan dependency yang jelas.
5. Setiap D maksimal 3,00 detik.
6. Informasi penting dari dialog yang tidak dipilih harus masuk ke narasi.
7. Dialog tidak perlu menyimpan pembukaan, pertanyaan, dan jawaban sekaligus jika salah satunya sudah cukup kuat.
8. Jangan mengulang utuh dialog terpilih di narasi tepat sebelum dialog diputar.
9. Untuk jenis DIALOG, Prompt 2 nanti mengikuti urutan kamera asli; Prompt 1B tidak boleh merencanakan pengacakan lokal pada Dialog.

Format:

`[D-xxx | HH:MM:SS,mmm --> HH:MM:SS,mmm | durasi | pembicara | fungsi]`

Contoh fungsi:

* reveal.
* threat.
* decision.
* confession.
* emotional peak.
* command.

# ATURAN JANGKAR AKSI

Jika jangkar AKSI dipilih:

* Fokus pada gerakan, benturan, perubahan kondisi, atau hasil tindakan.
* Dialog yang kebetulan terdengar tidak perlu dimasukkan kecuali benar-benar penting.
* Tentukan beat aksi utama.
* Untuk pertarungan panjang, bagi berdasarkan fase atau perubahan keadaan, bukan per pukulan.
* Prompt 1B belum menentukan potongan final, pengacakan final, atau pola AMBIL–LEWATI.

# AUDIT JANGKAR AKSI TERLEWAT

Setelah semua scene atau subbagian sudah mendapat seleksi jangkar normal, lakukan audit kedua khusus untuk adegan AKSI yang berpotensi terlewat.

Tujuan audit ini adalah memastikan momen visual penting yang sudah dinarasikan tidak hilang hanya karena tidak memiliki dialog kuat atau karena seleksi awal terlalu fokus pada percakapan.

Langkah audit:

1. Baca ulang setiap blok narasi yang sudah ditulis.
2. Tandai semua kalimat yang menggambarkan tindakan fisik atau perubahan visual penting, misalnya:
   * mengambil atau memegang benda penting;
   * menyerahkan, menyembunyikan, menjatuhkan, merusak, atau kehilangan benda;
   * membuka atau memasuki ruang penting;
   * serangan, benturan, jatuh, luka, darah, kerasukan, perubahan fisik, atau kematian;
   * perpindahan lokasi yang menentukan;
   * perubahan kondisi yang menjadi sebab atau akibat penting;
   * reaksi visual besar yang mengubah keputusan atau hubungan.
3. Periksa apakah setiap tindakan tersebut sudah terwakili oleh Jangkar DIALOG, AKSI, CAMPURAN, atau TRANSISI.
4. Jika belum terwakili, cari MP4 pada rentang scene terkait dan tentukan kandidat Jangkar AKSI baru.
5. Tambahkan Jangkar AKSI hanya jika momen tersebut memang membantu alur, kontinuitas, sebab-akibat, atau pemahaman visual.
6. Jangan menambah jangkar untuk gerakan kecil, perpindahan biasa, atau detail dekoratif.
7. Jangan menghapus jangkar hasil audit hanya karena jumlah total jangkar menjadi besar.
8. Tandai jangkar yang berasal dari audit ini dengan catatan:
   `SUMBER SELEKSI: AUDIT JANGKAR AKSI TERLEWAT`.

Audit ini wajib dijalankan setelah seleksi jangkar awal selesai dan sebelum jumlah jangkar akhir dianggap final.

# ATURAN JANGKAR CAMPURAN

Gunakan CAMPURAN hanya apabila dialog dan aksi benar-benar menjadi satu beat yang tidak dapat dipisahkan tanpa kehilangan makna.

Aturan CAMPURAN:

* Aksi adalah tulang punggung utama adegan.
* Dialog hanya berfungsi sebagai penguat beat aksi, bukan percakapan penuh.
* Jangan membangun CAMPURAN dari banyak dialog pendek yang sebenarnya masih bisa dirangkum oleh narasi.
* Setiap D-xxx di dalam CAMPURAN maksimal 3,00 detik dan sesingkat mungkin.
* Jika dialog dapat dihapus sementara aksi masih membawa beat utama, jenis jangkar boleh tetap CAMPURAN pada tahap Prompt 1B, lalu dapat diubah menjadi AKSI oleh Prompt 1B1 apabila pengguna benar-benar menghapus dialog tersebut saat edit manual.

# PEMBUKAAN KHUSUS PART 1

Part 1 wajib dimulai dari kejadian nyata film.

Buat tiga alternatif:

1. Aksi paling kuat.
2. Konflik paling kuat.
3. Momen penting paling kuat.

Pilih satu yang paling natural sebagai pembukaan final.

Simpan dua alternatif lain di bagian:

`Alternatif Pembukaan Tidak Dipakai`.

Dilarang memulai dengan:

* Ringkasan film.
* Penjelasan abstrak.

* Spoiler kejadian jauh di depan.

# SAMBUNGAN PART 2 DAN SETERUSNYA

Part 2 dan seterusnya wajib langsung melanjutkan cerita.

Aturan keras:

* Jangan menulis “di part sebelumnya”.
* Jangan menulis “pada part kedua”.
* Jangan mengulang premis film.
* Jangan memperkenalkan ulang tokoh yang sudah jelas.
* Jangan merangkum kejadian lama kecuali satu informasi benar-benar diperlukan untuk memahami tindakan sekarang.
* Paragraf pertama harus meneruskan akibat dari kejadian terakhir part sebelumnya.
* Periksa jangkar terakhir part sebelumnya agar tidak terjadi pengulangan adegan.

# PENUTUP PART

Part harus berakhir pada kejadian film, bukan komentar narator.

Dilarang:

* “Namun masalah belum selesai.”
* “Ia belum tahu apa yang menunggunya.”
* “Semua akan berubah.”
* “Cerita pun berlanjut.”
* “Di part berikutnya.”
* Kalimat rangkuman penutup.
* Prediksi.
* Teaser buatan.

Aturan:

1. Jika part berakhir pada Jangkar, berhenti setelah Jangkar tersebut.
2. Jika part berakhir pada narasi, narasi hanya menjelaskan kejadian terakhir.
3. Jika akibat adegan terakhir sudah jelas dari adegan asli, jangan tambahkan narasi lagi.
4. Jangan memanjangkan akhir hanya agar terdengar dramatis.
5. Jangan memperkenalkan kejadian part berikutnya.

# PEMBAGIAN ADEGAN

Gunakan struktur:

`ADEGAN 1 — Judul singkat`

Satu adegan biasanya mewakili:

* Satu lokasi dan tujuan.
* Satu konflik.
* Satu percakapan utama.
* Satu beat aksi penting.
* Satu perpindahan besar.

Jangan membuat adegan baru hanya karena kamera berganti.

Jangan membuat satu adegan sangat panjang apabila lokasi, tujuan, atau konflik sudah berubah.

# PERTARUNGAN PANJANG

Pertarungan panjang harus dibagi menjadi fase.

Contoh:

1. Kontak awal.
2. Tekanan meningkat.
3. Keunggulan berpindah.
4. Luka berat.
5. Klimaks.
6. Akibat.

Di antara fase, narasi boleh masuk kembali untuk:

* Menjelaskan akibat.
* Menjelaskan perubahan posisi.
* Menjelaskan keputusan.
* Menjaga blok aksi tidak terlalu panjang.

Jangan membuat satu Jangkar aksi sangat panjang tanpa pembagian apabila di dalamnya terdapat beberapa fase yang jelas.

# STATUS PRA-PENGUNCIAN DAN LARANGAN DRAF KASAR

Semua output Prompt 1B wajib memakai status `PRA-PENGUNCIAN 1B1`. Artinya Bagian A teknis dan Naskah Bersih awal sudah lengkap, utuh, dan matang, tetapi Naskah Bersih pada bagian paling bawah masih boleh diedit pengguna. Status ini tidak mengharuskan kata `Draf` muncul pada nama file.

Status pra-penguncian tidak boleh diartikan sebagai:

- narasi kasar;
- ringkasan sementara;
- hasil setengah jadi;
- placeholder;
- narasi yang belum selesai;
- pemilihan jangkar sementara;
- dialog atau aksi yang sengaja dibiarkan tidak lengkap;
- kualitas yang lebih rendah daripada Prompt 1B versi dasar.

Bagian teknis dan Naskah Bersih awal wajib langsung:

1. Utuh dari awal sampai akhir part.
2. Natural, rapi, kronologis, dan siap dibacakan sebagai voice-over.
3. Memiliki sebab-akibat yang jelas.
4. Mengikuti seluruh aturan gaya bahasa, dominasi narasi, pemilihan jangkar, batas dialog, aksi, pembukaan, sambungan, dan penutup part.
5. Tetap dapat dipahami ketika dialog dilepas dan hanya narasinya yang dibaca.
6. Memiliki ID N, D, dan J yang konsisten.
7. Sudah layak dianggap sebagai hasil final jika pengguna tidak melakukan perubahan.
8. Tidak menunggu Prompt 1B1 untuk melengkapi cerita atau memperbaiki kualitas penulisan.

Prompt 1B1 hanya menyelaraskan perubahan yang benar-benar dilakukan pada Naskah Bersih, lalu memperbarui bagian teknis dan mengunci hasil.

# NASKAH BERSIH EDIT MANUAL — WAJIB MENJADI BAGIAN PALING BAWAH

Gunakan format berikut pada hasil dokumen. Isi sebenarnya harus diisi lengkap sesuai part, bukan dibiarkan sebagai contoh kosong.

```text
============================================================
NASKAH BERSIH UNTUK EDIT MANUAL

[NARASI N-001]

“Teks dialog asli dari film.”

[NARASI N-002]
Teks narasi berikutnya.

[JANGKAR J-002 — AKSI — PENANDA POSISI SAJA]

[NARASI N-003]
Teks narasi berikutnya.
```

Aturan Naskah Bersih:

1. Narasi dan dialog wajib sama dengan isi awal pada Bagian A sebelum pengguna mengeditnya.
2. Tidak boleh ada timestamp, menit, durasi, sumber file, atau catatan teknis.
3. Penanda jangkar hanya menunjukkan posisi. Untuk jangkar aksi, jangan salin uraian teknis panjang ke bagian ini.
4. Setiap dialog dipisahkan menjadi blok ID D yang dapat dihapus atau dipendekkan secara mandiri.
5. Jika satu jangkar memuat tiga dialog yang dapat dikurangi satu per satu, buat tiga blok D terpisah.
6. Jangan menyatukan dialog yang tidak berurutan dalam satu blok D.
7. Dialog harus disalin dari sumber, bukan diparafrasekan oleh Prompt 1B.
8. Naskah Bersih wajib menjadi bagian terakhir setelah seluruh status dan catatan teknis Bagian A.

# TAHAP EDIT MANUAL WAJIB — TETAP SATU DOCX

Setelah Prompt 1B selesai:

1. Gunakan file yang sama: `Prompt 1B Part [N] [JUDUL FILM].docx`.

5. Simpan perubahan langsung pada file yang sama dengan nama yang sama.
6. Pengguna boleh memperbaiki, memendekkan, mengganti, menggabungkan, memindahkan, atau menghapus narasi.
7. Pengguna boleh mengurangi, memendekkan, menghapus, atau mengganti dialog.

11. Jika dialog pengganti tidak pernah ada dalam sumber, Prompt 1B1 dilarang mengarang timestamp dan wajib meminta keputusan pengguna.

14. Jalankan Prompt 1B1 menggunakan DOCX yang sama setelah diedit, ditambah MP4 dan SRT.
