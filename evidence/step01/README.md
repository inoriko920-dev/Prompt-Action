# STEP 01 Evidence

This directory records STEP 01 execution evidence. It must not contain credentials, API keys, user secrets, or generated product data.

Planned evidence:
- live repo HEAD before/after;
- dependency versions;
- test matrix T01–T15;
- relocation evidence;
- successful and failed startup log excerpts;
- protected-source diff check;
- Windows local test status and Windows CI status.
